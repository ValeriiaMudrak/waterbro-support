# WaterBro public website

This static website contains the public-facing WaterBro overview, Privacy Policy, Terms & Conditions, and Help & Support pages required for App Store submission.

## Routes

- `/waterbro/`
- `/waterbro/privacy/`
- `/waterbro/terms/`
- `/waterbro/support/`

The site is configured for static hosting from `dist`. Its legal text mirrors the September 30, 2026 in-app documents and identifies Valeriia Mudrak / Valeriia Labs as the United States operator. The support address is `hello.valeriialabs@gmail.com`.

Do not put a URL into App Store Connect until the corresponding deployment is public, stable, and accessible without signing in.
